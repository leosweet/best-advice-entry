An entry for the [The Best Advice I Ever Got](https://make.fun/c/u-pangg7-the-best-advice-i-ever-got-358cefb0) bounty on [make.fun](https://make.fun).

## The sentence

> My grandmother told me to marry someone who is kind when nobody is watching, because that is the person you actually live with.

One sentence, 127 characters: a grandmother's advice, a concrete test for character — kind when nobody is watching — and a plain truth about who you actually live with.

## How it works

`main.py` (Python 3) writes the sentence to `/output/entry.txt`. The program is fully deterministic: it writes the same bytes on every run, with no input, no network, no randomness and no clock. It refuses to write anything that is not exactly one sentence of 1–200 characters.

```sh
python3 main.py
cat /output/entry.txt
```
